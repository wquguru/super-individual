# 超级个体官网

这是一个使用 Next.js 构建的个人品牌官网，提供专业的技术咨询和职业发展指导服务。

## 技术栈

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- React Icons

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 启动生产服务器
npm run start
```

## 项目结构

```
app/
├── components/     # 可重用组件
├── lib/           # 工具函数和配置
├── styles/        # 全局样式
├── about/         # 关于页面
├── services/      # 服务页面
├── layout.tsx     # 根布局
└── page.tsx       # 首页
```

## 功能特点

- 响应式设计
- 三档次时间预约服务
- 技术咨询展示
- 职业发展指导
- SEO 优化

## 超级个体首页

目标：
1. 构建一个设计风格独特、令人印象深刻的超级个体（个人品牌）首页网站，模仿https://aliabdaal.com/ 的风格，将个人的时间做成3个不同的Package（分成1小时、8小时、定制时间三档）
2. 能力范围：React.js、Python、Golang、套利、职业咨询

## 实现步骤

1. 初始化Next.js项目

2. 理解https://aliabdaal.com/ 设计风格，输出成文档

3. 添加头部（Header）：
    * Logo: 简洁的个人品牌标志
    * 导航栏: 包含"首页""服务列表""关于我""联系方式""博客/案例"选项
    * CTA按钮: 醒目的"立即预订"或"查看服务"按钮，链接到服务页面

4. 添加英雄区（Hero Section）
    * 标题: 简洁有力的价值主张，例如"我是Jeff. 一个程序员转型的企业家."
    * 副标题: 补充说明服务类型，如"从职业规划到技能指导，按需定制您的时间包"
    * 视觉元素: 高质量的个人照片或服务相关插图（如日历、时钟），突出时间主题
    * CTA: "开始预订"按钮，引导用户浏览服务或注册

5. 服务展示区 
    * 卡片式布局: 列出时间包服务

6. 信任背书区
    * 客户评价: 展示用户反馈（即使是模拟的初期评价），如"通过1小时咨询，我找到理想工作！"  

7. 关于我区
    * 简介: 简述您的背景、技能和提供时间包服务的初衷（如"作为自由职业者，我希望用专业技能帮您节省时间"）
    * 照片: 亲和力的个人形象照，增加信任感
    * 社交链接: 链接到X、小红书等平台，展示活跃度

8. 常见问题（FAQ）区：回答用户疑虑，如"如何预订？""服务是否可退款？""线上还是线下？"  


9. 底部（Footer） 
    * 联系方式（邮箱、微信号）  
    * 隐私政策和服务条款链接  
    * 社交媒体图标（X、小红书、LinkedIn等）
